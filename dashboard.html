진동·전류 기반 유압펌프 이상 점검
내 PC에서만 처리
현장 검증 전 · 읽기 전용 시범운영　이상 점수는 KAMP 데이터 기준입니다. 실제 고장 확률·남은 수명을 뜻하지 않습니다. 센서 단위·수집 주기·전처리를 먼저 확인하세요. 설비 제어 기능은 없습니다.
운영 모드같은 모델, 목적에 따라 판단 기준만 바꿉니다

1. 데이터 불러오기

시간, 상부 진동, 하부 진동, 전류가 담긴 CSV를 선택하세요. 원본은 변경하지 않습니다.

컬럼 이름 맞추기

각 항목에 공장 CSV의 실제 컬럼 이름을 입력하세요. 단위 변환이나 재샘플링은 자동 수행하지 않습니다.

2. 폴더 감시

CSV가 저장되는 폴더의 전체 경로를 입력하세요. 파일 크기와 수정 시각이 2회 연속 같을 때 읽습니다. 파일마다 이력을 새로 시작하고, 화면에는 가장 최근 분석을 표시하고, 완료된 분석마다 ZIP을 결과 폴더에 자동 보관합니다.

결과 보관 폴더 (자동 ZIP 저장)

감시 중지

연속 PLC 수집기가 아닙니다. 저장 중인 파일보다 완료된 CSV를 시간별로 저장하는 방식이 적합합니다.

공개 데이터로 체험

KAMP 시험 구간을 재생합니다. 현장 실측 결과가 아닙니다.

방문 전 확인

센서 위치·단위·수집 주기

원시 신호인지, RMS·평균제거 값인지

Windows 64비트·브라우저·USB 허용

가동·정지·금형변경 및 정비 기록

CSV 반출 허용 범위와 현장 담당자

입력 형식(컬럼·간격·인코딩)과 현장 확인 항목은 프로그램과 함께 제공된 README.md의 ‘입력 계약’을 확인하세요.

분석할 데이터를 선택하세요

모델 연결 중
입력 표본—
점검 경보 · 진입 건수—
판단보류·입력오류 표본—
준비 표본—

경보 건수는 연속 경보 상태에 진입한 횟수입니다. 실제 고장 건수가 아닙니다. 판단보류·준비 표본은 정상으로 표시하지 않습니다.

이상 점수 추이

데이터 대기
청록: 이상 점수빨강 점: 점검 경보회색 점선: 경보 기준

가로축은 파일의 표본 순서입니다. 시간 공백은 연결하지 않습니다. 최근 1,000개 표본을 표시합니다.

상태와 점검 근거

시간상태이상 점수근거
CSV 분석 후 상태와 근거가 표시됩니다.

최대 최근 250행을 표시합니다. 전체 표본은 결과 ZIP의 predictions.csv에 저장됩니다. 경보 진입 행에는 배포 모델 SHAP 기준 주요 기여 특징이 함께 표시됩니다.

구간별 점검 우선순위

데이터 대기
순위구간 시작판정 표본기준 초과 비율평균 점수경보 진입

시간 공백으로 나뉜 연속 구간을 현재 운영 모드 기준 초과 비율 순(동률은 평균 점수)으로 정렬합니다. 점검 선별 모드에서 정기점검 대상 구간을 고를 때 사용하세요. 상위 10개를 표시하며 전체 순위는 결과 ZIP의 segment_priority.csv에 저장됩니다.

상태에 따른 현장 조치

관찰 · 단발성 이상입니다. 가동 시작·부하변경·금형교체 기록과 비교하세요.

점검 경보 · 지속성 기준을 충족했습니다. 담당자가 진동·소음·압력과 유지보수 필요성을 확인하세요.

판단보류 / 입력오류 · 수집 조건·센서·모델 적용 범위를 먼저 확인하세요. 정상이라는 뜻이 아닙니다.

하부 진동 정지 안내 · AI1 진동 표준편차가 약 0.026 이하(정지에 가까운 하부 진동)일 때 오경보가 집중되었습니다. 하부 센서 부착·배선·커넥터를 먼저 확인한 뒤 재분석하세요.

준비 · 새 측정 구간의 이력을 모으고 있습니다.

정상 범위 · 현재 모델 기준 미경보입니다. 설비 안전이나 무고장을 보장하지 않습니다.

작업자 확인 기록

예: 10:42 금형 교체 직후 경보. 담당자 점검에서 체결 이상 없음. 이 기록은 자동 재학습에 사용되지 않습니다.
